# GitHub publishing guide

This repository is intended to contain source, wallpaper SVG, scripts, and guides only. It must not contain a generated ISO, vendor packages, Flatpak bundles, private backups, virtual disk files, or signing keys.

1. Create a GitHub repository named `forge-os`.
2. Upload `README.md`, `COPYRIGHTS.md`, `GITHUB_GUIDE.md`, `INSTALL_SINGLE_BOOT.md`, `INSTALL_DUAL_BOOT.md`, `INSTALL_VMWARE.md`, `customize.sh`, `install.sh`, `apps.txt`, and `forge-os-wallpaper.svg`.
3. Commit with the message `Add Forge OS source and install guides`.
4. Leave the repository without a license unless you have chosen which reuse rights to grant.

The README links to all three installation guides. Keep any ISO private for personal testing; see [COPYRIGHTS.md](COPYRIGHTS.md) before considering distribution.
Include FEATURES.md and the complete features/ directory when copying this project to GitHub.
